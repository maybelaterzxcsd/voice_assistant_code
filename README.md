
# Голосовой AI-ассистент для управления задачами

Интеллектуальный голосовой и текстовый ассистент, который превращает естественную речь в структурированные задачи, встречи и напоминания.

Проект демонстрирует гибридный подход: LLM (GigaChat) используется исключительно для понимания намерений и извлечения сущностей (текст задачи, упоминание времени), а детерминированный Python-код отвечает за точный математический расчет дат и бизнес-логику. Это полностью исключает галлюцинации модели при работе с календарем.

## Стек технологий

- Backend: Python 3.10+, FastAPI, Uvicorn
- База данных: SQLite (SQLAlchemy ORM)
- AI / LLM: GigaChat API (Sber)
- Обработка текста: `thefuzz` (нечеткий поиск по смыслу), `dateparser`
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Голос: Web Speech API (встроенное в браузер распознавание речи (STT) и синтез (TTS))

## Быстрый старт

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone 
   cd voice_assistant
   ```


2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта и добавьте ваш ключ авторизации GigaChat:

   ```env
   GIGACHAT_AUTH_KEY=ваш_ключ_авторизации
   ```

5. Запустите сервер разработки:

   ```bash
   uvicorn app.main:app --reload
   ```

6. Откройте в браузере веб-интерфейс: **[http://127.0.0.1:8000/ui](http://127.0.0.1:8000/ui)**

_(Опционально)_ Чтобы наполнить базу тестовыми данными, выполните:

```bash
python import_csv.py
```

## Архитектурные решения

```text
voice_assistant/
├── app/
│   ├── database.py
│   ├── import_csv.py
│   ├── llm_service.py
│   ├── main.py
│   ├── models.py
│   ├── responses.py
│   ├── schemas.py
│   ├── search_service.py
│   └── session_manager.py
├── .env.example
├── .gitignore
├── events.csv
├── index.html
├── README.md
└── requirements.txt
```

- **`app/llm_service.py`**: Мозг системы. Классифицирует интенты и извлекает "сырой" текст даты/времени. **Важно:** LLM не вычисляет даты самостоятельно. Она возвращает фразу (например, "в пятницу"), которую парсит функция `parse_date_expression` на Python, опираясь на системное время.
- **`app/search_service.py`**: Использует библиотеку `thefuzz` для нечеткого поиска. Это позволяет находить задачи, даже если распознавание речи допустило небольшую ошибку или пользователь использовал синонимы.
- **`app/session_manager.py`**: Управляет контекстом диалога. Позволяет ассистенту задавать уточняющие вопросы (например, "На какое время?") и запоминать, о какой задаче шла речь в предыдущей реплике.
- **`index.html`**: Полностью клиентское распознавание речи с умным таймером тишины (автоотправка после 2.5 сек паузы), что делает взаимодействие плавным, как с Siri или Алисой.

## Реализованный функционал

-  **Создание задач** голосом или текстом с поддержкой относительных дат («завтра», «в пятницу», «до конца недели», «через 2 часа»).
-  **Диалоговый контекст**: если пользователь не указал время или дату для встречи/напоминания, ассистент вежливо переспросит.
-  **Умный поиск**: находит задачи по ключевым словам, игнорируя стоп-слова («найди», «про») и опечатки.
-  **Повторяющиеся задачи**: поддержка правил типа «каждый понедельник в 10:00» (требует расширения схемы БД).
-  **Просмотр расписания**: фильтрация событий на сегодня, завтра или на всю неделю.
-  **Безопасный перенос (Reschedule)**: ассистент находит нужную задачу по смыслу, предлагает новую дату и **запрашивает подтверждение** («да/нет»), чтобы исключить случайные изменения.
-  **Завершение задач естественным языком**: фраза _«я помыла посуду»_ автоматически найдет задачу и переведет её в статус `completed`.
-  **Удаление задач** голосовой командой.
-  **Защита от конфликтов**: ассистент предупредит, если вы пытаетесь создать встречу на время, когда у вас уже есть другое событие.
-  **Надежное хранение**: все данные сохраняются в SQLite и не теряются между перезапусками сервера.

## Планы по развитию (Future Work)

1. **Хранение сессий в Redis**: для поддержки масштабирования и сохранения контекста диалога при перезапуске сервера.
2. **Двусторонняя синхронизация**: интеграция с Google Calendar или Яндекс.Календарем через OAuth2.
3. **Push-уведомления**: реализация через WebSockets для реального оповещения пользователя в назначенное время.
4. **Семантический поиск**: переход от `thefuzz` к векторным эмбеддингам для поиска по смыслу, а не по совпадению символов.
